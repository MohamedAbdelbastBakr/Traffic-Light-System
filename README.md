# Traffic Light System

## Overview
This project implements a **Traffic Light System** using a shared-clock scheduler. The system uses two 8051 microcontrollers—**Master** and **Slave**—working in synchrony to manage traffic lights effectively. The synchronization is achieved through pulses generated by the Master, which invoke interrupts on the Slave. These interrupts trigger update functions in the Slave schedulers.

## Features
- Two microcontrollers: Master and Slave.
- Shared-clock scheduler for synchronized traffic light control.
- Interrupt-driven Slave operation for real-time updates.
- Modular driver-based design:
  - **MDio**: Digital Input/Output driver.
  - **Minterrupt**: Interrupt handler driver.
  - **Mtimer**: Timer management driver.
  - **Hseven segment**: Seven-segment display driver.

## Tech Stack
- **Language**: C
- **Environment**: Keil IDE
- **Microcontroller**: 8051

## System Architecture
1. **Master Microcontroller**:
   - Generates clock pulses.
   - Sends pulses to the Slave to maintain synchronization.
2. **Slave Microcontroller**:
   - Receives clock pulses as interrupts.
   - Updates its schedulers based on the received interrupts.
